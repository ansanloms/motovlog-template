バイク車載動画の
トンマナ

ゆるいトーク・長距離ツーリング・合成音声の解説が同居するシリーズを、1本ずつ作り直さずに積み上げていくための基準。色・文字・配置・画面の型を一枚ずつ決めていく。

全編ナレーション字幕 長距離ツーリング VOICEVOX 青山龍星
02

この動画は何でできているか

土台 / 70%
走行の記録

前方の風景と走行音。切らずに流す。ここが主役なので、他の要素はこの上に「乗る」だけ。

地の音 / 25%
青山龍星のナレーション

画面上の声はこれだけ。結論を急がない語り口で、その文字起こしが画面の主役になる。

要所 / 5%
章タイトル・注釈・写真

語らない区間は、章タイトルか注釈だけ。写真は画面中央に重ねるだけで、背景の映像はそのまま流す。速度・地名・時刻の常時表示はしない。

配合を守ることがトンマナの半分。残り半分がこれ以降の見た目の話。

03

コンセプトと3原則

走っている風景が主役。編集は、風景の邪魔をしない範囲で情報を静かに添える。

静かに足す

効果音・ズーム・派手なトランジションは使わない。カットは切り替えのみ。

同じ場所に置く

字幕は画面下中央、立ち絵は左。毎回同じ位置に置き、視聴者が探さなくていい状態を保つ。

説明しすぎない

ナレーションは全文を字幕にする。そのうえで、語る量そのものを増やさない。

05

タイポグラフィ

--subtitle 44px --w-bold 700 ナレーション字幕

--note 24px --w-regular 400 縦書きの注釈
書体

源ノ角ゴシック（Noto Sans JP）を全面で使用。ED も含めて例外なし。書体・ウェイト・映像上のサイズは CSS 変数（--font / --w-* / --title など6段）で持つ。ウェイトは左の表で段ごとに固定する。使うのは Regular / Medium / SemiBold の3つだけで、Bold 以上は使わない。左の6段以外のサイズは映像に出さない。装飾書体・毛筆・ポップ体は使わない。

映像の上での可読性

字幕は44px・白・太字。縁取りは使わず、画面下から348px（2行分・固定）の幅いっぱいの暗がりを敷いて読ませる。折り返しは暗がりの左右余白115pxいっぱい（幅1690px）。改行位置は台本側で指定する。行間1.45。

通常コメントは上から詰まる。ここに情報を置くと必ず隠れる。例外は写真紹介と右端の縦書き注釈だけ。

常設情報は置かない

速度・地名・時刻の常時表示はしない。出すのは字幕、章タイトル、注釈だけ。

字幕は下から8%

下1/4に幅いっぱいのごく薄い暗がりを敷き、その濃い側に置く。縁取りは使わない。

立ち絵は左・上半身・常時表示

画像の上から約52%（足の付け根）で切り、その線が画面下端に来る大きさ。左端から3%。走行中は出したままにし、章タイトル・OP/ED・サムネ用フレームの間だけ消す。右へ移すのは章の区切りでのみ、1本2回まで。

既定で全文に字幕を入れる。画面下中央、白のみ。記号や色分けで飾らない。

STANDING
立ち絵
左端・上半身・常時表示
足の付け根が画面下端

明るい路面や空に輪郭が溶けないよう影を付ける。重ねる写真も同じ扱いで、黒55%・ぼかし20px・下方向8px。表情は自由。章タイトル・OP/ED・サムネ用フレームの間だけ消す。

NOTE
注記テロップ
2024年に閉鎖

右端（右から67px・上から77px）に縦書きで上寄せ。1列の高さは768px、あふれたら左へ列を足す（列数の上限は設けない。運用では3列以内）。縁取り4pxだけで読ませる。

出し方 — 暗がりは語り出しの0.2秒前にフェードイン。字幕はフェードせず発話と同時に切り替え、無音が5秒続いたら暗がりだけ消す。
クレジット — 概要欄と ED に「VOICEVOX:青山龍星」を毎回記載。
禁止 — 速度・地名の常時表示、感情記号（汗・怒マーク）、笑い声SE。

10

出入りのタイミング

フェードは0.2秒を基準にし、OP・ED・サムネ用フレームの区切りだけ0.4秒。写真と注釈はフェードを使わずカットで出し入れする。尺は30fpsでフレーム割りできる値に揃える。

字幕フェードなしで発話と同時に切り替え。消えるのは音声終了＋0.4秒か次の発話開始の早い方
暗がり語り出しの0.2秒前にフェードイン。無音5秒で0.4秒かけて消す
章タイトル0.2秒フェードイン→2秒→0.2秒フェードアウト。章番号と題名の間隔は8px
立ち絵0.2秒フェードで出入り。左右を移すときはフェードアウト→フェードインで、横移動はしない
写真フェードなしで切り替える。背景の映像は暗くしない。表示時間と順送りの間隔は語りに合わせて任意
注釈フェードなしで出し入れする。3列に収まらない長さは出さず、概要欄に回す。列の間隔は16px
OP / EDOPは黒から0.4秒フェードイン。EDは最後のクリップからフェードなしでカットイン
サムネ用フレームEDから4.8秒かけてクロスフェードし、静止のまま終了。黒には落とさない

対象は1920×1080のみ。パレットはシリーズで固定し、1本ごとには変えない。

やらないこと

×効果音での間の埋め合わせ、笑い声SE
×BGM。全編を通して走行音だけで通す
×危険運転の見せ場化、速度の誇示
×他車のナンバー・顔をそのまま出す
×速度・地名・時刻の常時表示、画面を覆うワイプ
×サムネの過度な彩度・赤い矢印
×冒頭のチャンネル登録・高評価の依頼
×1本ごとに書体・色・配置を変えること
