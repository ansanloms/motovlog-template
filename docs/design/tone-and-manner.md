# 車載動画のトンマナ

見た目と出し方の正本はこの文書 (以下 T&M) とする。書体・色・配置・暗がりの出し方の決定の経緯は [ADR-0004](../adr/0004-define-tone-and-manner.md) にある。

上流は Claude Design プロジェクト『バイク車載動画のトンマナ設計』。取り込んだ版は `docs/design/upstream/` にあり、同期の手順と優先順位は CLAUDE.md の「Claude Design の同期」に従う。数値は 1920×1080 換算。

## 内容の配分

- 走行の記録: 70%
  - 主役。切らずに流す。
- 青山龍星のナレーション: 25%
  - 画面上の声はこれだけ。
- 章タイトルと注釈: 5%

## 3 原則

- 静かに足す: 効果音・ズーム・派手なトランジションは使わない。カットは切り替えのみ。
- 同じ場所に置く: 毎回同じ位置。
- 説明しすぎない: ナレーションは全文を字幕にする。語る量を増やさない。

- 書体は Noto Sans JP のみ。
- 映像中は字幕のみ Bold (700)。他は 400 / 500 / 600。
- 階層 (design 変数名):

| 変数名 | 値 | 用途 |

| `--title` | 96px | サムネの地名 |

## 画面配置

- 上部 1/3 には何も置かない。理由: 上部 1/3 に弾幕が溜まるため。この前提は未検証 (ADR-0004 の Assumptions を参照)。例外は写真紹介と右上の注釈。
- 字幕: 画面下中央、下から 86px。暗がりの濃い側に置く。
  - 暗がりは幅いっぱい、高さ 348px (上余白 134px + 字幕 2 行分 128px + 下余白 86px)。実際の行数によらず高さは固定する。理由: 字幕は最大 2 行のため。
- 立ち絵: 枠は左端から 10px、幅 513px、表示高 720px、画像は枠内で左 48px (画面上では左端から 58px)。画像の上から約 52% (足の付け根) で切る。影は黒 70%・ぼかし 28px (`--shadow-figure`) と、輪郭を締める黒 90%・2px (`--shadow-figure-edge`) の 2 重。画像は高さ 1379px に拡縮して上から 720px を出す (幅は 465px まで。配布素材の 1531px 高・462px 幅前後を想定)。常時表示し、章タイトル・OP/ED・サムネ用フレームの間だけ消す。右へ移すときは枠を右端から 10px に置く (画像の枠内オフセットは同じ)。移すのは章の区切りのみ、1 本 2 回まで。
- 注釈: 立ち絵の位置に関係なく右上。右端から 67px、上から 67px、最大幅 760px、padding 18px 28px、黒 62% の板に横書き、28px、行間 1.6、最大 2 行。URL は書かず「(概要欄)」とだけ書く。

## 字幕の出し方

- 既定で全文に字幕を入れる。白のみ。記号や色分けで飾らない。
- 暗がりはナレーションの開始の 0.2 秒前からフェードインする (フェードイン秒も 0.2 秒)。字幕はフェードせず発話と同時に切り替わる。
- 字幕は音声終了から 0.4 秒後、または次のナレーションの開始の早い方で消える (フェードなし)。
- 音声終了後 5 秒以内に次のナレーションが始まれば、暗がりは消さずに出したままにする。超えるなら、字幕が消えた直後 (通常は音声終了 + 0.4 秒) から 0.4 秒でフェードアウトし、次のナレーションの開始の 0.2 秒前から出し直す。最後のナレーションの後も同じ。

## 章タイトル

- 見た目: 字幕と同じ下部の暗がりに白文字を左寄せ。0.2 秒フェードイン → 2 秒 → 0.2 秒フェードアウト。
  - 帯や囲みは使わない。
  - その間は字幕と立ち絵を消す。
  - 章は 1 本 3〜5 個まで。
- 暗がりブロック内 (padding 134px 115px 126px、字幕より 40px 上)、章番号の前に幅 40px・高さ 2px の `--accent` の線を置き線と文字の間 16px、章番号と題名の間隔 14px、"CHAPTER n" 26px #9ED9AC (アクセント色) letter-spacing 0.12em、タイトル 56px weight 700 letter-spacing 0.02em #fff (白)。章番号の線ぶん 56px 字下げして題名を線の後ろの文字に揃える。

## 写真紹介

- フェードなしで切り替える。全画面にはせず、背景の映像もそのまま流す。複数枚の順送りもカットで行う (トランジションなし)。写真は立ち絵より後ろに置く。
- 写真を中央に重ねる。1 枚: left/right 480px (左右 25% を空ける)、top 96px、bottom 288px、`box-shadow 0 8px 20px rgba(0,0,0,0.55)` (`--shadow-photo`)。
- 2 枚以上: 縦写真は正方形に切る (中央基準のトリミング)。横に並べる (left/right 254px、gap 19px)。3 枚以上は並べずカットで順に切り替え、間隔は任意、1 回 6 枚まで。
- 表示時間はナレーションに合わせて任意 (固定秒数は決めない)。ズーム・パンなし。撮影日や場所は写真に添えない。

## OP・ED・サムネ用フレーム

- OP 4.8 秒: サムネと同じ絵を冒頭に。黒から 0.4 秒フェードインする。走行音でフェードインする。
- サムネ:
  - 構成: 走行写真・話数バッジ・地名・立ち絵 (右下)。地名は最大 12 文字。
  - 文字は左下。
  - バッジ: `rgba(26,44,34,0.85)` 角丸 6px、文字 32px #9ED9AC letter-spacing 0.08em。
  - 地名: 96px weight 600 行間 1.2。
  - 下地: `linear-gradient(to top, rgba(15,26,20,0.92), transparent)`。
  - 立ち絵: 枠 右 10px・562×933px、画像 枠内左 43px・幅 475px・高さ 1743px。
- ED 12 秒: 下地は `--bg`、書体は本文と同じ、余白は上下 115px・左右 134px。上段・中段・下段を縦中央に 48px 間隔で置く。文字だけで、枠・影・装飾は無い。最後のクリップからフェードなしでカットインし、走行音のフェードアウトで終える。
  - 上段: 左に `> RIDE LOG` (`>` は `--accent`、文字 26px `--ink-dim` letter-spacing 0.24em)、右に話数 `EP.12 / 愛媛` (26px `--ink-dim`)。下罫線 1px `--line-strong`、下余白 27px。
  - 中段: DATE・DISTANCE・RIDING TIME の 3 行。各行は高さ 92px、上下 21px の余白、下罫線 1px `rgba(26,44,34,0.9)`。ラベル 26px `--ink-dim` letter-spacing 0.12em、値 32px・行送り 48px・右寄せ。ROUTE 行は高さ 92px、罫線なし、値 32px・行送り 48px、場所を矢印「→」(`--ink-dim`) でつなぐ (5〜7 か所、時刻なし)。複数日は `2026.08.15-17` のように連ねる。
  - 下段: クレジット (`VOICEVOX: 青山龍星`、`立ち絵: Jacca さま`) を 26px `--ink-dim` 行間 1.5 で横に並べる (間隔 77px)。上罫線 1px `--line-strong`、上余白 28px。URL は出さず概要欄に置く。
- サムネ用フレーム 4.8 秒: ED から 4.8 秒かけてクロスフェードし、静止したまま終了する (黒には落とさない、投稿時にそのフレームを指定する)。写真を重ねるときは立ち絵と同じ影 (`--shadow-figure` と `--shadow-figure-edge` の 2 重、黒 70%・ぼかし 28px + 輪郭 90%・2px)。

## 出入りのタイミング

フェードは 0.2 秒を基準にし、OP・ED・サムネ用フレームの区切りだけ 0.4 秒にする。写真と注釈はフェードを使わずカットで切り替える。尺は 30fps でフレーム割りできる値に揃える (0.2 秒 = 6f、0.4 秒 = 12f、2 秒 = 60f)。

- 字幕: フェードなしで発話と同時に切り替える。消えるのは音声終了 + 0.4 秒か次の発話開始の早い方。
- 暗がり: 語り出しの 0.2 秒前にフェードインする。無音 5 秒を超えたら、字幕が消えた直後から 0.4 秒かけて消す (詳細は「字幕の出し方」参照)。
- 章タイトル: 0.2 秒フェードイン → 2 秒 → 0.2 秒フェードアウト。章番号と題名の間隔は 14px。
- 立ち絵: 0.2 秒フェードで出入りする。左右を移すときはフェードアウト → フェードインで、横移動はしない。
- 写真: フェードなしで切り替える。順送りもカット。
- 注釈: フェードなしで出し入れする。2 行に収まらない長さは出さず、概要欄に回す。
- OP・ED: OP は黒から 0.4 秒フェードイン。ED は最後のクリップからフェードなしでカットイン。
- サムネ用フレーム: ED から 4.8 秒かけてクロスフェードし、静止のまま終了する。黒には落とさない。

対象は 1920×1080 のみ。パレットはシリーズで固定し、1 本ごとには変えない。

## やらないこと

- 効果音での間の埋め合わせ・笑い声 SE
- 危険運転の見せ場化
- 他車のナンバー・顔
- 速度・地名・時刻の常時表示・ワイプ
- サムネの過度な彩度・赤い矢印
- 冒頭の登録依頼
- 1 本ごとに書体・色・配置を変えること
